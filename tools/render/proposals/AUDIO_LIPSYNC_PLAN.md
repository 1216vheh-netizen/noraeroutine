# 노래루틴 음성·영상 제작 방식 비교 계획 (설계안)

- 상태: 설계안 (승인 전). 실제 음성 생성·녹음·립싱크 제작은 하지 않았다.
- 유료 서비스 가입·결제·크레딧 사용 없음. 아래 서비스 조건은 **[확인 필요]** 표시가 있는 항목을 반드시 공식 약관 원문으로 다시 확인한 뒤 결정한다.

---

## 1. 제작 방식 3가지 비교

| 항목 | A. AI 음성 (TTS) | B. 실제 선생님 녹음 | C. 립싱크 (캐릭터 입 움직임) |
|---|---|---|---|
| 역할 | 내레이션·안내 멘트 | 내레이션 + **시범 발성·노래** | A 또는 B의 소리에 캐릭터 입을 맞춤 (단독 사용 불가) |
| 보컬 교육 신뢰도 | 낮음 — 발성 시범 불가, "선생님 목소리"로 오해되면 신뢰 손상 | 가장 높음 | 소리 품질에 따름. 입 모양이 어색하면 오히려 신뢰 하락 |
| 음정·호흡 시범 | 불가 (노래 합성은 별도 기술, 품질·권리 불확실) | 가능 | 해당 없음 |
| 제작 시간 (30초 1편 기준 예상) | 짧음 (문안 수정 → 재생성) | 중간 (녹음 일정·재녹음 필요) | 김 (클립별 확인·수정) |
| 비용 | 무료 등급은 대부분 **상업적 이용 제한** [확인 필요] | 녹음 장비·선생님 사례비 | 무료 도구는 품질·워터마크·상업 이용 제한 가능성 [확인 필요] |
| 권리 정리 난이도 | 서비스 약관에 묶임 | 서면 동의서로 정리 가능 | 원본 캐릭터 + 소리 + 도구 약관 세 가지 모두 확인 |
| 캐릭터 얼굴 고정 규칙(CLAUDE.md 4항) 위험 | 없음 | 없음 | **높음** — 립싱크 도구가 얼굴을 다시 그리면서 외형이 바뀔 수 있음 |
| 추천 용도 | 시안 검수용 임시 음성 | 게시본 기본 | 승인된 원본 클립이 생긴 뒤 시험 단계에서만 |

### 권장 순서
1. **시안 단계**: 지금처럼 싱크 신호음 + 자막으로 검수 → 필요하면 A(AI 음성)를 "임시 음성"으로만 사용 (게시 금지 표시).
2. **게시 단계**: B(선생님 녹음)를 기본으로 한다. 시범 발성은 반드시 실제 사람 녹음.
3. **C(립싱크)**: 공식 캐릭터 원본과 클립이 등록되고(`assets/characters/*/clips/`), 얼굴 위치 검사(`tools/face_check.mjs`)와 사람 검수를 통과한 뒤 별도 승인으로 시험한다. 그 전에는 **입이 움직이지 않는 장면 + 말풍선/자막**으로 대신한다.

## 2. 저작권·상업적 이용 조건 점검표

### 2-1. AI 음성 서비스
| 확인 항목 | 기준 |
|---|---|
| 상업적 이용 | 무료 등급은 비상업 한정인 경우가 많다 [확인 필요 — 사용할 서비스의 약관 원문] → 수익형 블로그·인스타 게시는 **유료 등급 필요 가능성**. 유료 결제는 대표 승인 사항 |
| 출처 표기 | 무료 등급에서 "○○로 생성" 표기를 요구하는지 [확인 필요] |
| 목소리 복제 | 선생님 목소리 복제는 **본인 서면 동의 + 서비스의 본인 확인 절차** 둘 다 필요. 동의 없이 복제 금지 |
| 플랫폼 표시 | 인스타그램·네이버의 AI 생성 콘텐츠 표시 정책 [확인 필요]. 표시 대상이면 게시 문안에 반영 |
| 기록 | `assets/voices/<id>/metadata` 에 서비스명, 요금제, 약관 확인일, 약관 화면 캡처 경로 기록 |

### 2-2. 실제 선생님 녹음
| 확인 항목 | 기준 |
|---|---|
| 실연자 권리 | 선생님은 녹음된 실연에 대해 실연자 권리를 가진다 → **서면 이용 동의서** 필요 |
| 동의서에 넣을 범위 | 사용 플랫폼(블로그·인스타·웹사이트·유료 강의 여부), 기간, 편집 범위, 얼굴 노출 여부, **AI 학습·목소리 복제 허용 여부(기본: 불허)**, 철회 시 처리 |
| 노래 시범 | 기존 곡을 부르면 작사·작곡 저작권이 걸린다. 반주 음원을 쓰면 음반 제작자 권리(저작인접권)도 걸린다 → DESIGN_SYSTEM.md 3장 규칙 적용 |
| 안전한 선택 | 직접 만든 연습 음계(도-레-미 계단, 립트릴 패턴 등)·자체 제작 반주 사용 → 권리 문제 최소 |

### 2-3. 배경음악(BGM)·효과음
- 라이선스가 명확한 음원만 사용(출처·라이선스 종류·상업 이용 여부·표기 문구 기록).
- 인스타그램 앱 내 음악 기능은 앱 안에서만 쓰는 조건이므로, 렌더링한 mp4에 미리 넣지 않는다 [확인 필요 — 계정 유형(비즈니스)별 사용 가능 음악 범위].

### 2-4. 립싱크 도구
- 결과물 상업 이용 가능 여부, 워터마크, 업로드한 얼굴 이미지를 도구 회사가 학습에 쓰는지 [확인 필요].
- 캐릭터 원본을 외부 서비스에 올리는 것은 **외부 서비스 사용**이므로 대표 승인 사항.

## 3. 기존 60초 렌더링 시스템과 연결하는 구조

### 3-1. 원칙
- 화면(자막·도형)은 지금 시스템(HTML → 프레임 → ffmpeg)이 그대로 담당한다.
- 소리와 캐릭터 영상은 **"재료"로 등록**하고, 장면 정의(spec)에서 시간만 연결한다.
- 장면 길이(30/40/60초)와 구간 구성(DESIGN_SYSTEM.md 6장)은 고정. 음성이 길면 **문안을 줄인다** (장면을 늘리지 않는다).

### 3-2. 장면 정의에 추가할 항목 (예시, 아직 코드에 넣지 않음)
```js
audio: {
  master: null,                    // 최종 믹스 파일(선생님 녹음 + BGM). 없으면 싱크 신호음 사용
  voice: [                          // 장면별 음성 조각
    { scene: 32.0, file: 'assets/voices/teacher-01/ep01_s07.wav', sha256: '…', in: 32.20 },
  ],
  bgm: { file: null, license: null, duckDb: -12 },
},
clips: [                            // 캐릭터 클립 (등록된 원본에서 만든 작업 사본만)
  { scene: 31.0, file: 'assets/characters/female/clips/v1_clip_explain_01.mp4',
    sha256: '…', face: 'assets/characters/female/clips/v1_clip_explain_01.face.json' },
],
```

### 3-3. 렌더링 흐름
```
specs/*.mjs ──▶ lib/build.mjs (HTML, 배경 투명 옵션) ──▶ 프레임
                                                     │
assets/characters/*/clips/*.mp4 ──(얼굴 위치 검사)──▶ ffmpeg overlay (클립 위에 글자 합성)
                                                     │
assets/voices/*  +  BGM ──▶ 믹스(덕킹·음량 맞춤) ──▶ ffmpeg 오디오 연결 ──▶ reel.mp4
                                                     │
                                          lib/validate.py 1~10 + 신규 11~20
```
1. **신호음 렌더링**(현재 방식): 화면 타이밍 검증 전용. 그대로 유지.
2. **실제 소리 렌더링**: 같은 프레임에 `audio.master`만 바꿔 붙인다. 화면을 다시 그리지 않아도 되므로 시간이 적게 든다.
3. 클립 장면은 HTML 배경을 투명으로 그린 뒤 클립 위에 얹는다. 클립은 같은 fps(30)로 맞추고, 클립 자체 소리는 쓰지 않는다(마스터 오디오만 사용).
4. 음성 시작 시간(`in`)과 자막 강조 시간(`data-in`)을 같은 값으로 맞추고, 검증 13번에서 차이를 잰다.

### 3-4. 단계별 진행안 (각 단계 대표 승인 후 진행)
| 단계 | 내용 | 필요한 승인 |
|---|---|---|
| 1 | 무료·로컬 방법으로 "임시 음성" 시험 (게시 금지 표시) | 사용할 도구 승인 |
| 2 | 선생님 녹음 동의서 양식 작성·검토 | 양식 승인 |
| 3 | 선생님 녹음 1편 분량 연결 + 검증 11~17 시험 | 녹음 파일 제공 |
| 4 | 캐릭터 원본 등록 → 클립 연결 → 검증 18~19 | 원본 등록 승인 |
| 5 | 립싱크 시험 (필요 시) | 외부 도구 사용 승인 |
