# 고정 캐릭터 원본 등록 구조 (준비용 · 이미지 없음)

- 이 폴더는 격리 작업 공간의 **양식**입니다. 원본 이미지·영상은 들어 있지 않습니다.
- 원본이 없으면 새 얼굴을 만들지 않습니다(CLAUDE.md 4항, DESIGN_SYSTEM.md 12장).
- 실제 등록은 대표 승인 후, 받은 원본 파일을 **확장자·내용 그대로** 넣고 체크섬을 기록합니다.

```
characters/{female,male}/
├── v1_reference.{원본 확장자}   # 공식 대표 원본 (미등록)
├── metadata.md                   # metadata.template.md를 복사해 작성
├── reference/                    # 각도·표정·입 모양 승인본
├── work/                         # 작업용 사본 (필요할 때만, 공식 원본 아님)
└── clips/                        # 승인된 영상 클립 + 얼굴 위치 파일(.face.json)
```
